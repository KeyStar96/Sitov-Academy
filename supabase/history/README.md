# Historische Importartefakte

Diese Dateien dokumentieren frühere Tabellen- und Importverträge. Sie werden **nicht** in die kanonische Datenbank eingespielt. Die SQL-Regressionen verwenden einzelne historische Seeds ausschließlich zum Testen der damaligen Migrationen.

Der vollständige aktuelle Inhaltsbestand steht in `../seeds/vps-content.sql`; das aktuelle Schema in `../schema.sql`. `scripts/build-grammar-curriculum.mjs` erstellt aus dem weiterhin erhaltenen Autorenmanuskript kanonische Grammatik-Imports. Die drei einmaligen Übersetzungs-/SQL-Skripte liegen hier als nicht ausführbare `.txt`-Dateien, nicht als aktive Wartungswerkzeuge.
