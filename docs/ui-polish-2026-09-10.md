## Neural Brain

`components/sections/Hero.tsx` behält die zweispaltige Hauptstruktur. Innerhalb des rechten Panels erhalten Überschrift, Canvas und Bildunterschrift eigene Grid-Zeilen in `HeroBrain.module.css`; die Bildunterschrift überlagert das Modell nicht mehr.

`components/effects/NeuralBrain.tsx` erzeugt 1.300 Knoten, 2.317 Kanten und 2.317 Signal-Sprites. Die Geburt jeder Kante ist zeitversetzt. Punkt und Schweif teilen dieselbe GLSL-Funktion und dieselben Endpunkte:

```glsl
vec3 edgeSignal(float seed, float edgeLength, float birth, float time) {
  float age = time - birth;
  float duration = 0.55 + edgeLength * 3.0;
  float period = 3.8 + seed * 3.2;
  float phase = mod(max(0.0, age - 1.35) + seed * period, period);
  float progress = phase / duration;
  float signalVisible = step(1.35, age) * (1.0 - step(1.0, progress));
  float backwards = step(0.5, fract(seed * 17.3));
  float position = mix(progress, 1.0 - progress, backwards);
  return vec3(position, signalVisible, backwards);
}
```

Der Vertex-Shader bewegt den Lichtpunkt auf der tatsächlichen Linie, einschließlich derselben leichten Verformung der Endpunkte:

```glsl
vec3 signal = edgeSignal(aSeed, aLength, aBirth, uTime);
vActive = signal.y;
vec3 point = mix(
  breathe(position, uTime),
  breathe(aTarget, uTime),
  clamp(signal.x, 0.0, 1.0)
);
```

Der Edge-Shader zeichnet zusätzlich den Schweif und lässt neue Kanten wachsen. Es werden drei Drawcalls und wiederverwendete Geometrien verwendet; pro Frame ändern sich Uniforms und Rotation. Unsichtbare Tabs/Canvas pausieren. Reduzierte Bewegung, fehlendes WebGL und verlorene WebGL-Kontexte verwenden eine statische Alternative. Die Browserprüfung hat einen reservierten GLSL-Bezeichner entdeckt; dieser ist in der finalen Fassung korrigiert. Linien und wandernde Lichtpunkte wurden im Produktionsbuild sichtbar geprüft.

## Gefüllte Audio-Wellen

`components/audio/FluidWaveform.tsx` zeichnet die erste Hauptkurve vorwärts und die zweite rückwärts. Dieselben Koordinaten werden anschließend für die Konturen verwendet:

```tsx
ctx.beginPath()
for (let step = 0; step <= CURVE_STEPS; step += 1) {
  const x = (step / CURVE_STEPS) * width
  if (step === 0) ctx.moveTo(x, curves[0][step])
  else ctx.lineTo(x, curves[0][step])
}
for (let step = CURVE_STEPS; step >= 0; step -= 1) {
  ctx.lineTo((step / CURVE_STEPS) * width, curves[1][step])
}
ctx.closePath()
```

Ein Farbverlauf füllt die eingeschlossene Fläche mit `ctx.fill('evenodd')`; so bleiben auch Kreuzungen korrekt. Die Deckkraft pulsiert im vorhandenen RAF-Loop, ohne einen zweiten Animationstimer einzuführen:

```tsx
fillOpacity = 0.24 + 0.045 * Math.sin((elapsedSeconds / 3.8) * Math.PI * 2)
```

Pause zeichnet eine ruhige Linie. Bei reduzierter Bewegung wird eine feste Kontur gezeichnet. Die Wiedergabe- und Aufnahmelogik bleibt unverändert.

## Verifikation und Grenzen

- `npm run build`: erfolgreich, einschließlich TypeScript-Prüfung und 114 generierten Seiten.
- Jest: **641 Tests in 39 Suites bestanden**; Aufruf mit `--runInBand --silent --testPathIgnorePatterns 'integration-real-db|/e2e/'`. Drei neue Tests prüfen die exakte Audio-Füllkontur, den Wiedergabe-/Pausenwechsel und reduzierte Bewegung.
- Fünf Dictionaries: dieselben 17 neuen Schlüssel, nichtleere Werte und konsistente Interpolationsparameter.
- Produktionsseite: Header/Canvas-Layout in allen fünf Sprachen bei 320px und 1280px; keine horizontale Dokumentüberbreite. Der mobile Buchungsbutton misst 288 × 50px bei 320px Viewport. Canvas und Bildunterschrift überlappen sich nicht. Porträt und Telegram-Ziel sind geprüft.
- Registrierung: tatsächliche Komponenten mit isolierten Server Actions und synthetischen Kursen. Kursauswahl und Kalender in fünf Sprachen bei 320px; zusätzliche Darstellung bei 430px/1280px. Persönliche Angaben, Vorwahlwechsel, Einwilligungen, Zusammenfassung und gemockte Erfolgsansicht geprüft. Labels stehen etwa 8px oberhalb der Eingabefelder. Ein Beispielkurs behält über alle drei Schritte denselben Betrag von 120 Euro für zehn Einheiten. Die Prüfung erzeugt keine Anmeldung und verschickt keine E-Mail.
- Audio: gefüllte, bewegte Konturen und Pausenzustand im Browser geprüft. Geometrie und Bewegungspräferenz zusätzlich durch Tests geprüft.
- `git diff --check`: erfolgreich.

Der lokale Produktionsbuild verwendet weiterhin die vorhandene Supabase-Platzhalterkonfiguration. Ein tatsächlicher Vertragsabschluss und das Versenden von Bestätigungen gegen Produktion waren nicht Teil dieser UI-Prüfung. Bekannte Build-Hinweise zur Middleware-Konvention, Browserslist und dynamischem Cookie-Zugriff der Registrierung bleiben unverändert.
