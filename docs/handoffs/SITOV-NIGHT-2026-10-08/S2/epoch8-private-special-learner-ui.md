No client score, permission grant or extra main-path blocker.

Explicit start uses a fresh request UUID and the chosen mode; the server returns the existing open account/node/mode run when present. Learning displays the authoritative queue head/count, spoken-answer instruction and German task. Only deliberate reveal obtains learningSolution. Only after it arrives do Correct/Try again later appear. Right removes and wrong rotates on the server; empty completed queue shows stack completion with no test score. Self-assessment does not become a main-path star or test proof.

Test uses PathExerciseForm for the private run's exact selected ten MC/gap/sentence items. Each answer is saved for its exact task UUID using run/revision/request UUID. Already persisted answers resume at the next unanswered selected task. All ten saved answers enable explicit submit; the authoritative result alone determines 7-fail/8-pass, displays score and per-task German prompt/student answer/solution plus localized explanation. New test round uses a fresh explicit start, leaving balanced/disjoint selection to95. The UI creates no replacement progress, box, checkpoint or streak model. There is no new historical completed-attempt list/API: current results are shown after submit, active attempts resume from server; broader history navigation remains a separate contract/UI need.

Every response is parsed with the actual strict private result schema and checked against expected node/run/mode/definition. Busy ref blocks duplicate simultaneous presses. Transport rejection/malformed uncertain response retains the exact immutable operation/request UUID/revision/answers/locale for retry; other actions are blocked until resolution. Definitive refusal clears the pending mutation. CAS/current-version/rights errors have an explicit get-only reload of the known owned run; no write retry with guessed revision. Not-ready/unavailable/partial-test scope/authentication states are localized and contain no invented tasks or scores. Back always returns to the intact main path. Account/node/locale changes remount the session and cleanup discards delayed responses from the prior identity.

All five interface languages and shared initially closed Help are provided. Actual task title/question/instruction/options/sentences/student answers/solutions use targeted German lang/translate attributes. PathExerciseForm's stored instruction/prompt/input attributes are also corrected without changing wording/IDs. Controls/help/explanations follow interface locale. Shared PressableCard/FeedbackMotion and MOTION values provide press, card-entry/reveal and genuine completion/result feedback; reserved task/solution regions avoid common reveal shifts. Reduced-motion disables transforms/transitions while preserving controls. Native keyboard/focus/48px actions remain. No persistent decorative loop/timer added.
