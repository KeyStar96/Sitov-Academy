## Proposed pedagogical contract

The written test measures language prerequisites, never pronunciation, rhythm, articulation, speed or an automated speech grade. A text-specific essential competency matrix cites exact private German source evidence and necessary vocabulary, actual article/case forms, verb forms, syntax and other occurring constructions. Absence of a category requires an explicit rationale; unrelated grammar must not become a gate.

For **each** essential competency: at least three independently authored items per attempt, at least six suitable pool items, and at least ceil(2*n/3) correct. Also require ceil(3*total/4) correct overall. For four competencies this is at least 12 items/9 correct with at least 2/3 in every competency. Five competencies yield at least 15/12; six yield 18/14. This is a proposed central standard for M approval, not the unrelated ten-item/80% Akkusativ rule. The per-competency floor prevents a strong aggregate hiding a missing core skill; three observations and two balanced disjoint retry forms avoid one lucky isolated choice. Validation must reject absent coverage, repeated trivial items, misleading distractors and title-only templates. Actual transfer sentences/distractors are authored for the actual text; changing a title never creates a test. A six-item pool is the minimum, not proof that its items are pedagogically equivalent.

No vocabulary/verb/path completion, CEFR milestone, word coverage, text-length tier, readiness score, hard override, VIP or checkpoint contributes to grading or passage. Retakes remain available without a new learning-completion requirement. Learning links address actual failed competencies and are optional recommendations, filtered through commercial access.

## Stable API proposal

`pretest-contract-v0.1.json` defines exact RPC signatures, action export names, sanitized catalog/attempt/task/result/proof shapes, error codes and storage rules. S4 sees `locked|available|in_progress|passed|failed`; internal `outdated` maps to a locked current catalog entry with `version_changed`, while the old attempt is retained. `not_started` maps to available only when a valid published definition exists. Commercially inaccessible target IDs are omitted, and targeted calls return `not_found`. A valid commercial entitlement permits starting with zero old learning evidence. Only a server-created current-version proof permits body/reference/new recording/new submission. S4 cannot derive permission from a local score.

A selected question set, definition and text version freeze per account-bound attempt. One open current-version attempt exists per account/text. Start/save/submit use request receipts and payload fingerprints; repeat payload returns its result, changed payload with the same key rejects. Save uses compare-and-swap revision. Submit validates exact selected item/option IDs and completeness, locks the attempt, grades private keys, and atomically commits terminal result plus exact passage. Competing tabs cannot double-grade or unlock another text. Identity always comes from auth.uid(); pupil endpoints never accept a student identity. New versions fail closed; only an explicitly reviewed, auditable compatibility mapping of exact fingerprints can transfer a passage. No compatibility row or pass is backfilled from hard mode, historical checkpoints, old recordings or VIP.
